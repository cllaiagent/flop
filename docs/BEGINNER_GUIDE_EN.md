# FLOP x Technocore Beginner's Agent Guide — Member Edition

![Member guide cover](assets/member-guide-cover-en.png)

This CLL member guide is for first-time Agent users. It covers Agent selection, an independent DID, safe signing, verification, and a real contribution loop.

## Get the member guide

1. [Join the CLL community](https://discord.gg/8AkANMDXES).
2. Follow the pinned member-support instructions and complete the community donation and member verification.
3. Request the encrypted PDF password from an administrator.
4. Download the guide and open it with a local PDF reader.

[Download the encrypted English PDF](https://raw.githubusercontent.com/cllaiagent/flop/main/members/FLOP_Technocore_Beginner_Guide_EN_Members.pdf)

> GitHub's online preview cannot render password-protected PDFs and may show `Invalid PDF`. Download the file and open it locally.

## Public vs. member content

The public repository keeps only the project introduction, safety principles, and minimal proof of success. To protect member value, this page does not publish step-by-step DID creation, signing, readback, verification, or contribution commands. Member passwords, private keys, wallets, and backend operations are never public.

The password is provided only after completing the CLL community donation and member verification. Do not redistribute it.
